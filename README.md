# ความทรงจำของเรา 💕

## วิธีรันใน VS Code
1. เปิดโฟลเดอร์ `our-memories` ด้วย VS Code (File > Open Folder)
2. ติดตั้งส่วนเสริม **Live Server** (ของ Ritwick Dey) ในแท็บ Extensions
3. คลิกขวาที่ `index.html` แล้วเลือก **Open with Live Server**

หรือจะดับเบิลคลิกไฟล์ `index.html` เปิดในเบราว์เซอร์เลยก็ได้ (ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์)

## วิธีแก้ข้อมูล
แก้ที่ `data.js` ไฟล์เดียว: ชื่อเล่น วันที่เริ่มคุย วันที่คบกัน จดหมาย และรายการความทรงจำ

## วิธีใส่รูป
1. เอารูปใส่ในโฟลเดอร์ `photos/` (แนะนำ .jpg ความกว้างประมาณ 1000-1200px ให้ไฟล์เล็กๆ)
2. ใน `data.js` ที่ความทรงจำนั้น ใส่ `photo: "photos/01.jpg"`

## วิธีแชร์เป็นลิงก์ให้แฟน
อัปโหลดทั้งโฟลเดอร์ขึ้น Netlify Drop (app.netlify.com/drop) หรือ GitHub Pages ก็ได้ ไม่ต้องตั้งค่าอะไรเพิ่ม

## ไฟล์ในโปรเจกต์
- `index.html` โครงหน้าเว็บ
- `style.css` หน้าตาและสี
- `script.js` ตัวนับเวลา การ์ด และแอนิเมชัน
- `data.js` ข้อมูลของเรา (ไฟล์ที่ต้องแก้)
- `photos/` ใส่รูปที่นี่

## อัลบั้มรูป (gallery.html)
1. เอารูปใส่โฟลเดอร์ `album/` แล้วตั้งชื่อเรียงเลข: `01.jpg`, `02.jpg`, ... ไปเรื่อยๆ ไม่จำกัดจำนวน
2. ไม่ต้องแก้โค้ดอะไร เปิด `gallery.html` (หรือกดปุ่มอัลบั้มในหน้าแรก) รูปที่เจอจะขึ้นเอง
3. ตั้งค่าเลขเริ่ม/จบ นามสกุล ได้ที่ด้านบนของ `gallery.js`
- ใช้ไฟล์ .jpg .jpeg .png .webp (รูป .heic จากไอโฟนต้องแปลงเป็น .jpg ก่อน)
- เลขต้องต่อเนื่อง ถ้าข้ามเกิน 15 เลขติดกัน ระบบจะหยุดหา

## คลังวิดีโอ (videos.html)
1. เอาวิดีโอใส่โฟลเดอร์ `videos/` แล้วตั้งชื่อเรียงเลข 3 หลัก: `001.mp4`, `002.mp4`, `003.mp4` ... ไปเรื่อยๆ ไม่จำกัดจำนวน
2. เปิด `videos.html` (หรือกดปุ่มวิดีโอในหน้าแรก) คลิปที่เจอจะขึ้นเอง
3. แนะนำ .mp4 (H.264) เพราะเล่นได้ทุกเครื่อง ไฟล์ .mov จากไอโฟนบางเครื่องเล่นไม่ได้ ให้แปลงเป็น .mp4 ก่อน
4. ตั้งค่าเลข นามสกุล ได้ที่ด้านบนของ `videos.js`
